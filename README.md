**Gladius for Ascension — Conquest of Azeroth (Vol'jin) World Of Warcraft**

Gladius adds enemy unit frames to arenas for easier targeting and focusing. It is highly configurable and you can disable most features of this addon.

Adapted for Ascension CoA: 21 custom classes, custom specs, and custom CC/DR/interrupt/cooldown tracking, while keeping normal 3.3.5a behavior.

**Modules**
Uses the 3.0 Arena Unit IDs for full functionality even if enemies are seen first in combat.

General arena unit frame features:
- HP bar + Text (including Ascension class colors)
- Mana bar + Text
- Cast bar + Text (including interrupt lockout)
- Class icon (vanilla + Ascension classes)
- PvP trinket status: Name icon, Name text, Big icon, Small icon, Grid-style icon
- Target of Target class icon (clickable / mouseover macros)

**Announcements**
New enemy, Trinket used/ready, Drinking, Low health, Aura used, Cooldown used.

**Auras**
Important buffs/debuffs on arena enemies. Add/edit/delete via config. Includes Ascension CC and control effects.

**Cooldown Tracker**
Enemy cooldowns. Enable/disable single cooldowns or entire classes, including Ascension custom classes.

**DR Tracker**
Diminishing returns on arena enemies. Toggle DR types/values. Includes Ascension custom DR mappings.

**Click actions**
Ten editable click actions with SHIFT/CTRL/ALT. Types: Target, Focus, Cast Spell, Macro.

**Slash commands**
- `/gladius ui` — configuration screen
- `/gladius test1-5` — test frames
- `/gladius hide` — hide test frame
- `/gladius trinket` — simulate trinket use
- `/gladius dumpclass` — print Ascension class tokens
